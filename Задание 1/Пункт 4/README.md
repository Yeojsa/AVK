### Cтатистика
- **Самый быстрый порядок на Си:** `ikj` во всех конфигурациях (достигает **0.000123 с** при $n = 128$ и **0.015460 с** при $n = 512$ с флагом `-O3 -march=native`).
- **Самый медленный порядок на Си:** `jki` (до **0.288054 с** при `-O2` и **0.397366 с** при `-O0` на $n = 512$).
- **Максимальное ускорение C относительно Python:** Си обгоняет Python в **1358 раз** на $n = 128$ (порядок `ikj`, `-O3`), а при $n = 1024$ ускорение составляет около **692 раз** (~0.124 с против 85.547 с).

### Вопросы
- И на маленьких ($n = 128$) и на больших ($n = 512$) матрицах наиболее быстрыми являются порядки `ikj` и `kij` благодаря чтению элементов строки матрицы $B$ подряд с единичным шагом, а самым медленным остается порядок `jki`. 
- По сравнению с реализацией на Python, эквивалентный порядок `ijk` на Си работает быстрее в 200-370 раз, а оптимизированный `ikj` с флагом `-O3` опережает Python в 690-1360 раз.
