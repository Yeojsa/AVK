# Пункт 1

Замеры выполнены на процессоре **13th Gen Intel(R) Core(TM) i9-13900HX** (микроархитектура Raptor Lake, AMD64):

- **Ядра и потоки:** 24 физических ядра (8 производительных P-ядер + 16 энергоэффективных E-ядер), 32 логических потока (`os.cpu_count() = 32`).
- **Базовая частота:** 2.20 ГГц (2200 МГц согласно Win32_Processor; текущая частота при замере `hz_actual_friendly` = 2.419 ГГц).
- **Кэш-память:**
  - **L1:** 2176 КБ суммарно:
    - P-ядра (8 ядер): 256 КБ L1d (по 32 КБ на ядро) + 384 КБ L1i (по 48 КБ на ядро).
    - E-ядра (16 ядер): 512 КБ L1d (по 32 КБ на ядро) + 1024 КБ L1i (по 64 КБ на ядро).
  - **L2:** 32768 КБ (32 МБ) суммарно:
    - 16384 КБ (16 МБ) на P-ядра (по 2 МБ на каждое из 8 P-ядер).
    - 16384 КБ (16 МБ) на E-ядра (по 4 МБ на каждый из 4 кластеров по 4 E-ядра).
  - **L3:** 36864 КБ (36 МБ общий).
- **Векторные инструкции:** поддержка SSE4.2 (`sse4_2 = True`), AVX (`avx = True`), AVX2 (`avx2 = True`), `avx512f = False`.

### Оценка пиковой производительности одного ядра

#### Для FP32 (float):
- **При частоте замера 2.419 ГГц (из `cpu_report.py`):**
  - $2.419 \times 8 = 19.35$ GFLOPS (без FMA)
  - $2.419 \times 8 \times 2 = 38.70$ GFLOPS (1 блок FMA)
  - $2.419 \times 8 \times 2 \times 2 \approx 77.4$ GFLOPS (пик 2 блоков FMA для P-core)

#### Для FP64 (double):
- **При частоте замера 2.419 ГГц:**
  - $2.419 \times 4 = 9.68$ GFLOPS (без FMA)
  - $2.419 \times 4 \times 2 = 19.35$ GFLOPS (1 блок FMA)
  - $2.419 \times 4 \times 2 \times 2 = 38.70$ GFLOPS (2 блока FMA)

### Вопросы
- **Кэш** - это сверхбыстрая память процессора в которой хранятся часто используемые данные и инструкции, чтобы процессор не обращался каждый раз к более медленной оперативной памяти.
- Несколько ядер нужны процессору для одновременного выполнения разных задач и ускорения параллельных вычислений.
- **Такт** - это один цикл работы процессора в течение которого выполняются определённые операции.
